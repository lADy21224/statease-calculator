How to enter your dataset

  1. Open Calculator and select Ungrouped data for a regular list of observations.
  2. Enter one value at a time. Separate values with commas, spaces, semicolons, or new lines.
  3. Choose the number of decimal places for displaying your answers.
  4. Click Calculate results. Review the mean, median, mode, range, solution, frequency table, and chart.

Accepted dataset formats

Whole and decimal numbers4, 0.1, 2.75, 10
Positive and negative numbers-5, -2, 0, 3, 6
Fractions1/2, 1/4, 3/4Fractions are converted to decimal values for calculation.
Percentages10%, 25%, 12.5%Percentages are divided by 100 before calculation.
Mixed formats in one dataset1/2, 0.75, 25%, -1.5, 2You may combine whole numbers, decimals, fractions, percentages, and negative values in the same ungrouped dataset.

Important: Use a period for decimal points (for example, 2.5). Do not use commas inside a single number because commas separate data values.

How to enter a frequency table

  1. Choose Frequency table (value and frequency) under Data type.
  2. Enter one value-frequency pair on each line, using value,frequency.
  3. The value may be a whole number, decimal, fraction, or percentage. The frequency must be a positive whole number.

System Limitations

Important boundaries and special cases to know when using the calculator.

Calculation limit

  • A calculation can contain up to 10,000 observations, including expanded frequencies.
  • Values must be valid finite numbers. Fractions cannot have a zero denominator.

Frequency-table rules

  • Each row must contain one value and one frequency.
  • Frequency must be a positive whole number. Zero, negative, and fractional frequencies are not accepted.

Mode special cases

  • No mode: every distinct value occurs once.
  • Multiple modes: all values tied for the highest frequency are reported.
  • A dataset with one observation has no mode unless the value is repeated in a larger dataset.

What the system calculates

  • Mean, median, mode, range, sorted data, frequency distribution, and data visualization.
  • The chart displays up to 20 distinct values at a time.
  • Variance, standard deviation, and other advanced statistical tests are not included.
